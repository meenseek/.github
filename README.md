# meenseek Organization

이 저장소는 `meenseek` GitHub Organization의 공개 프로필과 저장소 운영 모델을
관리합니다.

- [`profile/README.md`](./profile/README.md): Organization 공개 프로필
- [`docs/repository-model.md`](./docs/repository-model.md): 저장소 경계와 조건부 확장 기준

운영 모델은 미래 저장소의 생성 계획이 아니라, 실제 반복이 확인되었을 때 경계를
판단하기 위한 기준입니다. 현재 상태는 항상 GitHub의 실제 저장소를 기준으로
확인합니다.
