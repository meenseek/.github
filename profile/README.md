# meenseek

작게 만들고, 실제로 써 보고, 검증된 것만 기반으로 남깁니다.

각 제품은 자신의 도메인과 배포를 독립적으로 소유합니다. 공통 코드는 반복되는
문제가 확인된 뒤에만 별도의 계약으로 분리합니다.

## 현재 작업

### Measure Twice

개인 사이드 프로젝트에서 실용적이고 선명하며 담백한 경험을 반복해서 만들기 위한
React 디자인 시스템입니다.

- [Repository](https://github.com/meenseek/measure-twice-design-system)
- npm: [`@measure-twice/react`][measure-twice-npm]
- [Storybook][measure-twice-storybook]

### Tarot Spark

카드를 뽑고 읽기 방식을 선택해 AI 해석용 프롬프트를 만드는 독립 타로 제품입니다.

[Repository](https://github.com/meenseek/tarot-spark)

### Grid Cell

공간 방향 감각을 가볍게 시험하고 결과를 공유하는 독립 실험입니다.

[Repository](https://github.com/meenseek/grid-cell)
